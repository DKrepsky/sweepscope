## Project facts

- Docs: `docs/prd.md`, `docs/architecture.md`, `docs/design.md` (design system, draft awaiting G2), `docs/design-prototype/` (tokens.css is the canonical token values; index.html main window; components.html state sheet; main-window.png).

## Human preferences (design)
- SweepScope is an engineering tool, not a web app: dense, precise, front-panel logic (Run, Vertical, Horizontal, Trigger). No cards, gradients, big radii, decorative whitespace.
- DARK THEME ONLY (dark gray). Overrides PRD DSP-6; PRD 8.4 and architecture 5.2 need amending.

## Decisions
- Token naming `--ss-<category>-<role>[-variant][-state]`, source path with dots maps mechanically.
- Channel colours (colour-blind searched, min dE 34): ch1 #f2e24a, ch2 #2fd0d8, ch3 #b08cff, ch4 #ff6a5c; math white thin, ref grey dashed, cursor light grey dashed. Colour never alone (number badge, marker, row border).
- Rejected: rotary knob widgets (imprecise, inaccessible) in favour of Stepper (wheel, arrows, double-click reset); modals during acquisition (use TaskPanel/Banner/Toast).
- Run/Stop = one toggle labelled with the action + separate state chip.
- Honest-hardware: Fs/Ts/record/capture rate/live-dead share always in status bar; `?` unverified badge, `SW` badge, `-` with footnoted reason for invalid values; cursor X relative to trigger with +-6 sample note.

## Lessons
- Designers specify PRESENTATION (slot, component, badge, wording pattern, state look) and flag technical questions to engineering in a 'Questions for engineering / PM' section. Never assert hardware or computation rules (sample-rate formulas, aliasing thresholds, accuracy, trigger uncertainty, unverified lists); cite PRD 5.2 and requirement IDs. Label prototype numbers as illustrative placeholders.
- Every gesture needs target, effect, feedback, result when it cannot apply; double-click reset only for fixed defaults (no '50 % of amplitude'). Each component/interaction gets given/when/then acceptance criteria.
- Responsive: rem-based tiers (W1 >=90rem, W2 80-90, W3 64-80, scroll <64; heights H1 >=56, H2 50-56, H3 45-50 provisional), content floor 64x45rem (scroll below, toolbar and status pinned, AC-L1..3), screen locked 10:8 min 32x25.6rem never clipped. 1024x576 cannot hold the screen minimum plus dock: do not promise it. Window minimum 1024x720 recommended (D-L1). W3 toolbar hides brand, captions and Single/Force/Autoset text (ratified).
- Graticule/frame lines are 1-device-pixel hairlines at every DPR (not 1 CSS px). Stop colour proposal #f2766f (D-L2, human approval): #e5534b was 3.64 on bg-raised.
- Scaffold deferrals: status bar right-align, Unverified footnote, ultrawide sidebar growth, key M.
- Regenerate main-window.png: google-chrome headless --hide-scrollbars --window-size=1440,900 on index.html.
- PRD 5.2 says time cursors are relative to samples, not the trigger: do not design trigger-relative X.
- Chrome headless works for screenshots: `google-chrome --headless=new --no-sandbox --disable-gpu --window-size=W,H --screenshot=out.png file://...`; put scratch shots in `.claude/tmp/`.
- CSS grid children need `minmax(0,1fr)` or the layout overflows; avoid reusing short class names (`.sw`) across badge and swatch.
- Prototype SVG traces are generated by a python script (scratchpad, not committed); index.html is static output.
- Contrast split (WCAG 1.4.11): `border-subtle/border/border-strong` are decorative (panel/group/dialog outlines, dividers, no 3:1 needed); control boundaries use `color-border-control` #7b858f (>=3:1 on panel, inset, raised, hover). Trace criterion 6.5:1 (ch4 measures 6.68). Quote measured contrast, not rounded-up values, in criteria.

## M3 Analyse decisions (pending G2)
- Persistence grading by age in opacity only (hue unchanged); rejected heat-map hue ramp and density-only brightness (rare glitch would be dimmest). Ghost contrast numbers measured in spec 5.2.
- FFT: Window as Menu button (4-word Segmented does not fit the Horizontal column), peak marker panel replaces Cursors panel in sidebar; XY keeps Time/div, X/Y selectors replace Trig pos and Interp rows.
- Alias warning as badges in 4 places, no banner (banner costs height, flickers). Math = fixed 5th row in Vertical group (dock height impact). Recording token status-record pink.
- Pitfall: there is no M2 design spec and no docs/design-system folder; design.md is the system. Prototype generator pattern: slice docs/design-prototype/index.html by markers and link its tokens.css/prototype.css relatively.
