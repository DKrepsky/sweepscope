M4 wireframe: calibration status tag in the status bar (static, dark only)

The tag sits at the right end of the status bar (essential priority: it stays when the status bar drops items; the Renderer item drops first). It is a button: click, Enter or Space opens the calibration dialog. Hover or keyboard focus shows the accuracy summary tooltip. The state is text plus icon, never colour alone. The existing Accuracy button and popover are replaced by this tag (decision D4).
