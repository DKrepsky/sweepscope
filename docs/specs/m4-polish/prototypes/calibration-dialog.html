M4 wireframe: calibration dialog states (static, dark only)

Modal dialog (native dialog element, showModal): focus is trapped, Esc = Cancel, the scrim covers the window, acquisition is paused while open. Each state keeps the same header, channel progress row and footer so nothing jumps. Numbers and wording are illustrative placeholders.

Flow

Focus on open and on every step change goes to the step heading (programmatic, tabindex="-1") for screen readers, with no visible ring: a heading is not interactive. Only controls and the scrollable offset table (keyboard scrolling) show the 2 px focus ring.

Why calibrate

Calibration measures the zero error of each input while it is shorted and subtracts it, so small voltages read correctly.

  • You short each of the 4 inputs in turn
  • Acquisition is paused while this dialog is open
  • Nothing is stored until you finish, and the factory calibration is never changed
